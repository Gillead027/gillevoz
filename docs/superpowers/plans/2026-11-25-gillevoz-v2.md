# GilleVoz v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o GilleVoz num app com Flow Bar animada, Hub com configurações, texto em tempo real digitado onde o usuário escreve, e um instalador `.exe` — mantendo o motor 100% local.

**Architecture:** O pacote Python `gillevoz` vira um motor sem janela (`python -m gillevoz --motor`) que conversa por linhas JSON em stdin/stdout. Um app Electron em `ui/` (electron-vite + React + TypeScript) abre e vigia o motor e desenha a Flow Bar, o menu, o Hub e a bandeja. Inno Setup empacota Electron + Python 3.12 embutível + motor.

**Tech Stack:** Python 3.12 (.venv do projeto), faster-whisper, sounddevice, pywin32, pycaw, pytest · Node 24, Electron, electron-vite, React 19, TypeScript, Motion (`motion/react`), `@tabler/icons-react`, `@fontsource/chakra-petch`, `@fontsource/red-hat-mono`, vitest, electron-builder · Inno Setup 6.

**Spec:** [docs/DESENHO-V2.md](../../DESENHO-V2.md) e [docs/REFERENCIAS-UI.md](../../REFERENCIAS-UI.md) (micro-interações, tempos e licenças — obrigatório para as Tasks 7–9) (ler junto). Estudo de referência: [docs/ESTUDO-WISPR-FLOW.md](../../ESTUDO-WISPR-FLOW.md).

## Global Constraints
- Python sempre do `.venv` do projeto (`.venv\Scripts\python.exe`, 3.12). Nunca o `python` 3.14 do sistema.
- No modo `--motor`, **stdout é só do protocolo** (uma mensagem JSON por linha, UTF-8). Nenhum `print`.
- Nada rouba o foco: janelas da barra e do menu com `focusable:false` e `showInactive()`.
- A área de transferência é sempre restaurada (reusar `paste.colar`).
- Dados do usuário em `%APPDATA%\GilleVoz\` (variável `GILLEVOZ_DADOS` sobrescreve, usada nos testes).
- Atalho padrão mãos livres: `ctrl+shift+space`. Atalho só de modificadores é recusado.
- Identidade: fundo `#000004`, superfícies `#0B0912`/`#14111C`, borda `#241E30`, texto `#F3EFE6`/`#9A93A8`,
  escala térmica `#000004 #320A5E #781C6D #BB3754 #ED6925 #FBB61A #FCFFA4`, primário gradiente `#781C6D→#ED6925`,
  erro `#BB3754`; fontes Chakra Petch + Red Hat Mono locais; ícones Tabler. Sem roxo→azul, glassmorphism, emoji
  ou qualquer asset do Wispr Flow.
- Molas: tamanho da pílula `stiffness 600, damping 35`; elementos internos `stiffness 300, damping 28`.
- Interface toda em pt-BR.
- O projeto não era repositório Git: a Task 1 cria o repositório; todo commit termina com
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. **Microfone ocupado/desconectado ao começar a gravar** → barra vai para `erro` com "Microfone indisponível" e volta a ocioso; motor não trava. Teste na Task 6.
2. **Fala só com silêncio/ruído** (Whisper devolve vazio ou "Obrigado.") → nada é digitado, nada vai ao histórico. Teste na Task 6.
3. **Usuário aperta parar logo depois de iniciar (<0,3 s)** ou aperta o atalho várias vezes rápido → sem digitação dupla, sem thread de tempo real órfã. Teste na Task 6.
4. **config.json com chave de tipo errado ou trocas/atalhos malformados** (ex.: `trocas: "x"`) → motor ignora o item ruim, registra no log e segue. Teste na Task 2.
5. **Motor fecha/cai no meio de uma gravação** → Electron reinicia, barra volta a ocioso, sem janela de erro presa. Teste na Task 9.

### Task 4: Tempo real — concordância e digitador

**Files:**
- Create: `gillevoz/tempo_real.py`
- Test: `tests/test_tempo_real.py`

**Interfaces:**
- Consumes: `texto.aplicar_trocas`, `texto.achar_gatilho`, `texto.maior_k` (Task 3).
- Produces:
  - `class Concordancia`: `alimentar(hipotese: list[str]) -> list[str]` devolve as palavras recém-confirmadas: prefixo comum (por `normalizar`) entre a hipótese atual e a anterior, **além** das já confirmadas na janela atual. `nova_janela()` zera a hipótese anterior e o contador da janela (o texto confirmado global continua). `finalizar(hipotese_final: list[str]) -> list[str]` devolve `hipotese_final[n_janela:]` (o que falta). Atributo `confirmadas: list[str]` (global).
  - `class Digitador(digitar: Callable[[str], None], apagar: Callable[[int], None], trocas: list, atalhos: list)`: `receber(palavras: list[str])` acumula, aplica trocas e gatilhos e digita tudo menos as últimas `maior_k` palavras; `descarregar()` digita o resto; `texto` (str) = tudo que foi digitado. Espaço entre palavras; primeira palavra sem espaço antes. Gatilho: substitui as palavras do gatilho ainda não digitadas pelo texto pronto (nunca chama `apagar` para texto já digitado nesse caso; `apagar` existe só para o caso de o gatilho ter sido parcialmente digitado — não deve ocorrer com K correto; se ocorrer, apaga exatamente os caracteres digitados por ele).

Algoritmo de `alimentar` (o resto o implementador decide):
```python
comum = 0
while comum < min(len(hip), len(self._anterior)) and normalizar(hip[comum]) == normalizar(self._anterior[comum]):
    comum += 1
novas = hip[self._n_janela:comum] if comum > self._n_janela else []
self._n_janela = max(self._n_janela, comum)
self._anterior = hip
self.confirmadas += novas
return novas
```
